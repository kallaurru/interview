Для отсортированного по не убыванию массива целых чисел А, индекс элемента index и целое число K.
Необходимо вернуть в любом порядке K чисел из массива, которые являются ближайшими по значению к элементу A[index].

РЕШЕНИЕ:
1. Тестами описываем все возможные варианты. Index = 0, n, last item.
2. Организация цикла - пока К не станет 0
