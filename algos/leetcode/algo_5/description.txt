5. Longest Palindromic Substring

Given a string s, return the longest palindromic substring in s.

Example 1:

Input: s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.

Example 2:

Input: s = "cbbd"
Output: "bb"

Example 3:

Input: s = "babab"
Output: "babab"

Example 4:

Input: s = "baddab"
Output: "baddab"

Example 5:

Input: s = "baddac"
Output: "adda"


Constraints:

1 <= s.length <= 1000
s consist of only digits and English letters.
